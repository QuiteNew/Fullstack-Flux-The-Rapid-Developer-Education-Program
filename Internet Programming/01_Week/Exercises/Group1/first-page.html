My First Web Page

Everything you see here is plain text marked up with tags. The browser reads those tags and decides what each piece of text is — a heading, a paragraph, a link — and then draws it accordingly.

About this page

This file exists to show the four things every HTML document is built from: a title, headings, paragraphs, and links. Open it in a browser, then open the file itself in your editor and read the two side by side.

Then press Ctrl+U in the browser. That is the exact text the server sent — there is no hidden layer underneath it.

How paragraphs work

A paragraph is a <p> element. It starts on a new line and gets space above and below it, automatically.

This is a second paragraph, so it is separate from the first one. Notice what HTML does not care about: pressing Enter, or adding many spaces, changes nothing. Whitespace in the source collapses into a single space. If you want a new paragraph, you write a new <p>.

Inside a paragraph

Some tags mark up a piece of text rather than a block of it: strong for importance, em for emphasis, code for code, and a link for a link.

The three kinds of link

A link is an <a> element — "a" for anchor. Its href attribute says where it goes, and the text between the tags is what the reader clicks. There are three ways to write that destination.

1. Absolute — to another site

The full address, protocol included: MDN's HTML reference. Adding target="_blank" opens it in a new tab: the W3C validator.

2. Relative — to another file of your own

No protocol, no domain — just a path from where this file sits. This one points at the other page in this folder: the DOM playground. Relative links keep working when you move the whole folder to a server, which absolute ones do not.

3. Fragment — to a spot on a page

A # plus an id: back to the contents. Combine it with a path to land on a specific section of a different page.

A link does not have to point at a web page at all. This one opens a mail client: send an email.
